# Simplify live-update internal runtime protocol

Follow-up to the strict typed live-surface overhaul: remove the remaining internal compatibility abstractions and evaluate whether the browser wire protocol can be simplified now that feature code is strictly typed.

## Design

Keep typed surface authoring intact. First remove untyped internal surface compatibility without changing browser JSON, then consider a deliberate protocol migration if the value outweighs the frontend/test churn.

## Acceptance Criteria

No untyped LiveSurfaceDefinition/mkLiveSurface/mkDefinedLiveSurface compatibility layer remains. Internal wire primitives are named as transport types, actor refresh payloads are produced through typed helpers, docs/tests describe the simplified runtime, and any browser JSON change is covered by compatibility or migration tests.
