# Unify app toggles as green active button controls

Replace Bootstrap switch-style toggle UI with a shared green active/inactive button toggle pattern across roster, timesheets, admin, Xero, billing, and existing profile toggle-button controls.

## Design

Build a reusable view/helper + CSS + JS contract for binary toggles. The checked state renders as btn-success; unchecked renders as btn-outline-success. Preserve existing form/HTMX semantics, labels, role/aria state, and no-JS fallback behavior where forms submit normally.

## Acceptance Criteria

No app-owned form-switch switch controls remain except intentionally documented non-toggle cases; existing hidden-checkbox button toggles use the shared pattern; active/inactive state is visually consistent and accessible; focused Hspec/E2E coverage for roster, timesheet filters, admin settings, Xero show-matched, and billing controls passes.
