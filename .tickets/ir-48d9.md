# Add guardrails for raw TypeScript generator scaffolding

Prevent new contract-looking TypeScript exports from being added as ad-hoc strings in the generator.

## Design

Add grep/AST guardrails around Application.Helper.FrontendContract.TypeScript allowing generic renderer combinators but rejecting raw exported type/function/const blocks outside approved emitters or explicit, documented exceptions.

## Acceptance Criteria

Guardrail fails for a new raw `export type Foo = ...` string outside approved renderer helpers; docs describe allowed renderer templates; frontend-check passes.
