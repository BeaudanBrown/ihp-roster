# URL-encode query string helper usage

Replace the raw-concatenating appendQueryParams helper with a URL-encoding implementation and add regression tests so future callers can safely pass arbitrary text values.

## Design

Prefer a structured URI/query renderer from the platform stack rather than manual string concatenation. Keep existing URLs stable for UUID, bool, date, and integer callers.

## Acceptance Criteria

appendQueryParams encodes keys and values, preserves existing simple-path behavior, handles existing-query paths, omits empty values as today, and has tests for spaces, ampersands, equals signs, unicode-safe text where supported, and tokens.
