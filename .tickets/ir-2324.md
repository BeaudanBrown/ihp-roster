# Unify roster staff-drag and shift day-column drop highlight styling

Staff drag drop highlights in day-row and day-column views should use the same visual styling as dragging a shift onto a day column.

## Design

Consolidate roster dropzone highlight classes/CSS tokens so staff drag targets in both day-row and day-column views share the established day-column shift-drop highlight treatment. Avoid adding feature-specific JavaScript when existing typed interaction/dropzone classes can drive the styling.

## Acceptance Criteria

Staff drag targets in day-row and day-column views use the same highlight styling as shift-to-day-column drop targets. Empty slots, existing shifts, and day-column targets remain visually consistent across roster layouts. Focused CSS/markup or interaction coverage verifies the shared class/token usage.
