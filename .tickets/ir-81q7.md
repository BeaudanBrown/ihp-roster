# Split roster controller and grid rendering by concern

Thin the roster root controller and grid renderer by moving behavior groups into focused modules.

## Design

Move shift dialog parsing/validation, slot-definition actions, row actions, move intent helpers, and response helpers out of Web/Controller/RosterWeeks.hs where practical. Split Web/View/RosterWeeks/Grid.hs into focused layout/fragments, day/row rendering, slot/cell rendering, and card/control modules. Preserve routes, action constructors, URL-driven week semantics, DOM ids, HTMX targets, live fragment semantics, and roster FrontendSurface metadata.

## Acceptance Criteria

Roster controller/root grid module are noticeably thinner. Stable wrappers keep external call sites clear. bash ./bin/in-env typecheck passes. Focused bash ./bin/in-env hspec-test --match "RosterWeeks" or a documented subset passes.
