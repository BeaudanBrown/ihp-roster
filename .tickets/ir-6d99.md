# Introduce Payroll nav, routes, page shell, and live resources

Rename the user-facing Xero surface to Payroll and prepare shared routes/fragments for provider-neutral workflows.

## Design

Add Payroll action/routes/page shell/live resources while keeping owner/super-admin visibility. Preserve legacy Xero URLs through redirects or compatibility routes where useful. The shared shell should host provider connection status, setup, sync, mappings, pay items, timesheets, and provider-specific fragments through the provider interface.

## Acceptance Criteria

Authenticated navigation says Payroll instead of Xero. Owner/super-admin access rules are unchanged. Existing Xero users can reach the migrated Payroll page without losing context. Live update scopes/resources are provider-neutral and existing Xero fragments are either migrated or isolated behind compatibility wrappers.
