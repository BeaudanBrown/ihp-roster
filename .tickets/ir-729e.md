# Migrate roster interactions to generated refs/runtime

Migrate roster drag/drop and activation behavior from semantic markers to generated role-specific refs and the manifest-backed runtime.

## Design

Migrate roster grid drag/drop source/dropzone markers and roster layout-mode activation. Preserve existing opaque source/target key server validation, disposable effects, conflict behavior, and DOM-owned HTMX forms. Update tests to exercise the new runtime path.

## Acceptance Criteria

- Roster views no longer use old semantic interaction marker helpers for migrated interactions.
- Roster frontend interaction tests pass against the new runtime.
- Hspec/controller tests still pass.
- Focused e2e is run or explicitly deferred with rationale if drag/drop behavior changes visibly.
