# Migrate remaining admin typed live surfaces to SurfaceImpl

Remove TypedLiveSurfaceDefinition/LiveSurfaceConfig usage from admin views and make admin rendering consume Web.Admin.FrontendSurface SurfaceImpls exclusively.
