# Spike codec-first frontend contract generator options

Compare an autodocodec/schema-tooling approach with a small custom FrontendCodec approach using representative app contracts.

## Design

Prototype LiveUpdateScope, LiveFragmentProtection, LiveSurfaceConfig, InteractionDom, IntentFormContract, and LiveSurfaceManifestEntry in both candidate approaches. Evaluate whether each option can produce JSON encode/decode, TypeScript types, runtime validators, and typed constants from one Haskell source of truth. If autodocodec or external tooling is used, add it only through Nix/devenv/package configuration in the spike branch and document exact commands.

## Acceptance Criteria

A short decision note is recorded in docs/workstreams/frontend-codec-contracts.md; generated TS/validator examples for both options or a documented reason one was rejected early are available; Nix impact is documented; the selected approach is justified against single-source truth, output quality, validator generation, ergonomics, and build complexity.
