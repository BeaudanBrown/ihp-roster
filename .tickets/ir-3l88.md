# Add refactoring radar architecture query

Turn architecture facts into ranked refactoring targets for agents.

## Design

Add architecture_query hotspots or refactoring-radar. Score controllers by action count, mutation/fragment count, wrapper coverage, handler LOC estimate, direct calls, table refs, realtime refs, missing policies. Score modules by fan-in/fan-out/cross-subsystem imports. Score schema tables by domain/audit hub characteristics. Combine OTel costs later when available.

## Acceptance Criteria

The query returns summaries/tables/warnings ranking likely refactoring targets with provenance and confidence. It does not require diagrams to be useful, but may emit focused artifacts for top targets.
