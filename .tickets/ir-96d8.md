# Move profiling header emission into response middleware

Refactor request profiling so final timing headers are emitted from a WAI response middleware instead of requiring each action to remember renderProfiled/respondHtmlProfiled.

## Design

Store the active RequestProfile in request/vault-level state that middleware can read at response finalization. Keep controller helpers for manual spans, but make Server-Timing and X-Request-Id automatic for HTML, redirects, JSON, downloads, and error responses. Ensure finalization happens after IHP render/response construction so app_total includes render/serialization work where possible.

## Acceptance Criteria

Profiled requests emit Server-Timing/X-Request-Id without per-action profiled render helpers; existing profiled roster/timesheet/leave/Xero responses still report spans; redirects/JSON/download/error responses are either covered or explicitly excluded with tests; typecheck and focused profiling helper tests pass.
