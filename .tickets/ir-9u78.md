# Build guided Xero draft-timesheet preparation modal

Replace the separate Xero payroll readiness chores with a single panel-instigated workflow modal. The modal prepares draft timesheets for a user-selected Xero pay period, runs connection/reference/pay-item/staff/readiness checks, stages automated actions for approval, then shows preview before final draft submission.

## Design

Entry point remains in the Xero admin timesheet panel. The panel opens an HTMX workflow dialog in the shared dialog overlay mount. Preparation is an application-level orchestration flow, not controller glue. OAuth reconnect remains native full-page when required. Staff auto-matches are proposed only and require approval before persisting. Manual staff mapping is still allowed through dropdown controls in the modal, but there is no separate match button. Staff can also be marked not paid through Xero persistently or skipped for only this preparation run. Managed pay-item creates require approval in the same modal. Existing Xero timesheets block create in v1. Posted pay runs hard-block the selected period.

## Acceptance Criteria

Venue owner/super-admin can select a Xero pay period, open a modal, see preparation progress/results, approve proposed mappings/pay-item creates/selections, manually choose Xero employee mappings from dropdowns when needed, skip staff for this run, mark staff not paid through Xero persistently, reach a deterministic preview only after blockers are resolved, and submit draft timesheets separately after preview. Modal uses shared overlay patterns and is covered by focused Xero Hspec plus at least one E2E workflow.
