# Store active live subscriptions as FrontendSurface data

Change LiveBus state from closed LiveUpdateScope subscriptions to generic FrontendSurface subscription records.

## Design

Introduce a server-side FrontendSurfaceLiveSubscription/ActiveSubscription value with surface name, scope payload, scope key, mounted fragments, connection, and client metadata as needed. Version state should key by generated scope key plus canonical scope identity instead of old ADT constructors. Broadcast paths should be able to target subscriber-local mounted fragments.

## Acceptance Criteria

LiveBus registration, unregistration, active subscription queries, current version, and broadcast tests pass using surface-native subscription records. Existing websocket subscribe/unsubscribe behavior is preserved.
