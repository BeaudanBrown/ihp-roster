# Build MYOB import mapping read model and preflight validation

Provide a shared service/read model that resolves MYOB import mappings and reports actionable blockers before file generation.

## Design

Fetch active venue staff, approved source entries/pay segments, staff card mappings, payroll category mappings, and optional job mappings. Validate mandatory MYOB fields, duplicate or blank employee card IDs, unmapped pay buckets, field length limits, date/unit renderability, tab/newline handling, and expected file-size constraints. Return structured blockers/warnings for UI and export service use.

## Acceptance Criteria

Preflight validation catches missing staff card IDs, missing payroll categories, duplicate card IDs, over-length names/categories/jobs/notes, unsupported source rows, and file-size risks before an export job is created. The read model is reusable by setup UI and payload generation.
