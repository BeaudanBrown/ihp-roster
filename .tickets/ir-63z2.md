# Mobile UI focus, toggle, week control, and snapping cleanup

Coordinate removal of automatic focus, app-wide toggle unification, shared roster/timesheet week controls, and reusable mobile horizontal snapping without changing desktop toolbar behavior.

## Design

Break work into independently verifiable epics. Keep desktop week headers in the current one-row layout; apply row reordering only to narrower breakpoints. Do not introduce initial auto-scroll for snapping.

## Acceptance Criteria

No app-owned page or overlay automatically focuses an input on load/open; switch-style toggles use a unified green active/inactive button pattern app-wide; roster and timesheet week controls share a reusable helper with approved mobile ordering; roster snapping is preserved and timesheet day-column snapping is enabled with regression coverage.
