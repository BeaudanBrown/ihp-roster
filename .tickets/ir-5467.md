# Migrate shared frontend constants and overlay lanes

Move small shared constants/unions such as OverlayLane and shared interaction event/DOM constants into codec/schema-generated contracts.

## Design

Define codec/schema-backed DTOs/enums/constants for OverlayLane and any shared DOM/event names used by both Haskell and frontend. Constants emitted to TS must be annotated with generated types, not untyped 'as const' blobs.

## Acceptance Criteria

OverlayLane and selected shared constants are generated from codec/schema definitions; no stringUnionDeclaration use remains for shared concepts covered by this ticket; frontend imports generated constants/types where practical.
