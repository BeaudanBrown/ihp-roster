# Generated FrontendSurface interaction manifest and surface polish

Replace semantic `data-bepis-*` interaction marker wiring with a generated `FrontendSurface` interaction manifest, role-specific minimal DOM refs, surface-instance-centric browser runtime, and typed Haskell render helpers. Keep DOM-owned HTMX forms as the concrete mutation transport. Delete the legacy semantic marker protocol before closing the epic, then polish naming/docs.

## Design

`FrontendSurface` is the source of truth for interaction semantics. Static/generated metadata declares refs, sessions, intents, fields, layers, effects, and conflict policy. Feature views keep owning HTML layout but attach generated role-specific refs and dynamic opaque keys through typed helpers. The browser hydrates mounted surface instances, resolves refs through the generated manifest, manages sessions/effects generically, validates payloads against generated schemas and DOM-owned HTMX forms, then dispatches generated form triggers. During implementation, the old semantic marker runtime may coexist, but deletion and guardrails are required before epic close. Mount JSON must not become a custom mutation transport contract; concrete HTMX action URLs, hidden fields, targets, swaps, sync, and disabled selectors remain server-rendered DOM form concerns.

## Acceptance Criteria

- Production interactive surfaces use generated role-specific refs instead of semantic marker attrs for migrated behavior.
- Browser interaction runtime is mounted-`FrontendSurface`-instance-centric.
- Intent/session/dropzone behavior is derived from generated manifest metadata.
- HTMX forms remain DOM-owned and server-rendered.
- Old semantic marker protocol is deleted or restricted to explicitly allowed transitional test fixtures before close.
- Docs and guardrails describe the new architecture.
- Existing roster interaction behavior remains covered.
- Verification passes: `bash ./bin/in-env typecheck`, `bash ./bin/in-env frontend-check`, `bash ./bin/in-env hspec-test`, and focused e2e where browser behavior changes substantially.
