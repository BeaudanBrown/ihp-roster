# Remove active toggle from new staff creation

Make new staff active by default and remove the active setting from creation UI.

## Design

Update staff create forms/controllers so new staff rows are active by default. Keep existing edit/disable pathways for staff after creation. Avoid changing trial-staff adoption semantics.

## Acceptance Criteria

New staff creation does not show an active toggle and creates active staff. Existing staff can still be disabled from the appropriate edit/admin flow. Focused staff/admin tests pass.
