# Add Stripe contract and lifecycle test harness

Build a rigorous Stripe Billing test harness around request builders, OpenAPI/fixture contract checks, a strict localhost mock, webhook fixtures, Stripe CLI sandbox testing, and Billing test-clock lifecycle scenarios.

## Design

Use Stripe's official OpenAPI repository as a contract reference where practical, but treat Stripe test mode, CLI webhook forwarding/triggers, and Billing test clocks as the idiomatic integration validation path. Keep CI deterministic with local mocks and snapshot fixtures; keep sandbox/live checks opt-in and secret-file backed.

## Acceptance Criteria

Tests cover Checkout Session creation against the existing recurring Price lookup/key, Customer Portal session creation, webhook signature verification, duplicate event handling, subscription lifecycle event parsing, delayed payment events, controller access paths, notification triggers, read-only enforcement interactions, and an operator-run Stripe CLI/test-clock checklist.
