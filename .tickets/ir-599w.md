# Descriptor-first live surface definitions

Reduce live-surface boilerplate by introducing descriptor/default helpers that derive common TypedLiveSurfaceDefinition fields while preserving explicit auth, routes, and dependencies.

## Design

Add non-breaking descriptor primitives and defaults first, then migrate representative simple surfaces and registry manifest derivation incrementally. Keep generated frontend contracts stable unless intentional.

## Acceptance Criteria

Simple live surfaces can be declared with descriptors/defaults; common defaults cover empty interaction, default fragments, fragment target selectors, and manifest metadata; focused typecheck, frontend contract, and live-surface tests pass.
