# Migrate successful profile update responses

Use actor-local semantic invalidation plus extras for successful profile updates.

## Design

Successful HTMX profile updates should commit through existing mutation/touched-resource paths, return toast extras as needed, and emit actor-local semantic invalidation for the relevant active profile section. They should not render the active profile content fragment as authoritative OOB business HTML. Validation/preference errors remain direct-rendered in the target form/content where needed.

## Acceptance Criteria

Successful HTMX profile update responses contain no business OOB active content fragment. They emit actor-local invalidation for the correct profile section and include only extras such as toasts. Tests confirm active section behavior and no stale hand-built success path remains.
