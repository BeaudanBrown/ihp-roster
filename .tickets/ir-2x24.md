# Build MYOB timesheet preview payloads from provider-neutral previews

Convert approved Bepis payroll facts into deterministic MYOB Timesheet request previews.

## Design

Reuse provider-neutral preview grouping where possible, then adapt to MYOB Timesheet shape: one employee/period payload, Lines grouped by PayrollCategory UID, Entries with date and hours, source entry/pay-version metadata preserved, and no payroll processing in Bepis.

## Acceptance Criteria

Preview is deterministic without calling MYOB. It preserves source timesheet entry ids and pay snapshot versions, renders the MYOB request shape for audit/review, and blocks unsupported line/category combinations before submission. Tests cover date ordering, grouping, and JSON payloads.
