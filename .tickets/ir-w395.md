# Add typed shift-type highlight user preference

Persist the per-user shift-type highlight preference using the existing typed user_preferences model.

## Design

Add show_shift_type_highlights BOOLEAN DEFAULT TRUE NOT NULL to Application/Schema.sql and a matching migration. Regenerate generated types. Extend Application.Helper.UserPreferences with default/fetch/upsert helpers, preferably fetching roster layout and highlight preferences together when useful. Follow the existing roster_layout_mode upsert pattern and keep the table typed rather than introducing generic JSON preferences.

## Acceptance Criteria

Schema and migration define show_shift_type_highlights with default TRUE and NOT NULL. Generated types compile. New users or users without a row resolve to highlights enabled. Helpers can persist false and true without changing roster_layout_mode. Existing roster layout preference tests/behavior remain valid.
