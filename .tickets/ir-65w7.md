# Derive interaction static schemas from registered FrontendSurfaces

Replace the hard-coded InteractionStaticSchemas registry shape with data derived from registered FrontendSurface interaction declarations.

## Design

Keep InteractionContract responsible for generic runtime record shapes and DOM attrs only. Generate the static schema registry from surfaces that declare interactions, starting with RosterSurface, without adding compatibility shims or duplicate legacy aliases.

## Acceptance Criteria

Interaction static schema output is derived from registered surfaces; roster interaction schema content remains functionally equivalent; no hard-coded roster-only static schema registry authority remains in InteractionContract/TypeScript generation; frontend and focused interaction tests pass.
