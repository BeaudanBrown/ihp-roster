# Archived Numbered Plans

The old numbered `plans/` files were moved here during the 2026-05-02
documentation refactor.

These files are preserved as historical design context. They may contain stale
status, superseded implementation instructions, or future ideas that have since
moved to `docs/workstreams/` and GitHub Issues.

When using an archived plan:

1. Read the linked GitHub issue first.
2. Check `docs/workstreams/` for active future work.
3. Check subsystem-local `SPEC.md` files for implemented behavior.
4. Treat archived plan prose as background, not authority.
